# Altyn Montazh — телефоннан жарнама креативі

Компьютерсіз, **тек телефонмен** жарнама видео жасайтын шаблон. Креативтің 3 түрі:

1. **Түсірілген видео** — өзіңіз немесе клиент камераға сөйлейді. Claude кеседі, субтитр қояды, сөзге сай анимация мен графика салады, музыка, соңғы экран және обложка қосады.
2. **ИИ суретімен видео** — адам түсірмейді. Claude сценарий мен сурет сұраныстарын жазады → суретті ChatGPT-де, дауысты ElevenLabs-та жасайсыз → Claude видео жинайды.
3. **Мульт-оқиға** — кейіпкері бар қысқа оқиға, соңында бренд.

Автор: [@altyn_khassan](https://instagram.com/altyn_khassan)

## Не керек
- Телефонда **Claude** қосымшасы (ақылы жазылым: Pro немесе одан жоғары).
- **github.com** аккаунты (тегін).
- 25 МБ-тан үлкен видео үшін — Google Drive.

## Баптау (бір рет, ~10 минут)
1. **Өзіңізге көшіріп алу.** Осы бетте жасыл **«Use this template»** → **«Create a new repository»** → аты, мысалы `montazh` → **Private** → **«Create repository»**.
   (Батырма көрінбесе: браузер мәзірінен «Сайттың компьютер нұсқасы / Desktop site» қосыңыз.)
2. **GitHub-ты Claude-қа қосу.** Claude қосымшасы → **Code** → жаңа сессия → репозиторий таңдау → GitHub-та **Only select repositories** → өз `montazh` репозиторийіңіз → **Save** → Claude-қа оралу.
3. **Тексеру.** Сессияда жазыңыз: «Сәлем, бәрі дайын ба? Тексерші». Claude керек құралдарды өзі орнатады (бірінші рет 3–5 минут).

## Қалай қолданамыз

### 1-түр: түсірілген видео
1. Видеоны түсіресіз: тік, бетіңіз ортада, жарық алдыңыздан, басында бірден негізгі ой.
2. Видеоны Claude чатына жібересіз (немесе GitHub-тағы `Бастапқы` папкасына саласыз).
3. Жазасыз: **«Монтаж жаса»**.
4. Claude сұрақтар қояды — жауап бересіз (келіссеңіз «ок»).
5. **Раскадровка** (кадрлар суреті) келеді — қарап, «ок» немесе правка жазасыз.
6. Дайын видео мен обложка чатқа келеді → «Бөлісу» → «Видеоны сақтау».

### 2-түр: ИИ суретімен видео
1. Claude-қа жазасыз: **«ИИ суретімен жарнама жасайық»** және не жарнамалайтыныңызды айтасыз.
2. Claude сұрақтар қояды, сосын сценарий береді: әр сахнаға **сурет сұранысы** (ChatGPT-ге көшіріп қоясыз) және **дауыс мәтіні** (ElevenLabs-қа қоясыз).
3. Суреттерді **ретімен** (1, 2, 3…) және дауыс файлын (mp3) Claude чатына жібересіз.
4. Раскадровканы мақұлдайсыз → дайын видео келеді.

### 3-түр: мульт-оқиға
Жазасыз: **«Мульт-оқиға жасайық»**. Claude кейіпкер мен оқиғаны ұсынады, әр көрініске сурет сұранысын жазады. Әрі қарай 2-түрдегідей.

💡 Кеңес: кейіпкер барлық суретте бірдей болуы үшін суреттерді ChatGPT-дің **бір чатында** жасаңыз.
