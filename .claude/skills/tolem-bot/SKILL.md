# Төлем боты

Пайдаланушы телефонмен жұмыс істейді. Код, json, wrangler туралы айтпа. Әр қадамды қарапайым тілмен, бір-бірлеп бер, әр қадамнан кейін «болды» деп жазуын күт.

```bash
BT="python3 .claude/skills/tolem-bot/scripts/bot.py"
```
Баптаулар: `Боттар/<аты>/config.json` (COURSE_NAME, COURSE_DESC, PRICE, KASPI_URL, ADMIN_ID, CHANNEL_ID).

## Бот қалай жұмыс істейді (пайдаланушыға осылай түсіндір)
1. Клиент ботқа кіреді → курс аты, бағасы, **«Kaspi арқылы төлеу»** батырмасы.
2. Төлейді → чекті (скриншот/PDF) ботқа жібереді.
3. Чек **курс иесіне** келеді: астында **✅ Растау / ❌ Бас тарту**.
4. Иесі Kaspi-ден ақша түскенін тексеріп, «Растау» басады → бот клиентке жабық каналдың **бір реттік** сілтемесін жібереді.
5. Клиент чек орнына сұрақ жазса — ол да иесіне жіберіледі.

## 1. Сұрақтар — БІР хабарламада, нөмірлеп, ұсынысыңмен
1. **Курстың аты** және бір сөйлем сипаттамасы.
2. **Бағасы** (мысалы «6 990 ₸»).
3. **Kaspi төлем сілтемесі** бар ма? (Kaspi Pay — `https://pay.kaspi.kz/pay/...`). Жоқ болса: Kaspi Pay бизнес-қосымшасында (ИП керек) «Төлем сілтемесі» жасау керегін айт. ИП жоқ болса, Kaspi Gold нөмірін «аударым» ретінде жазуға болатынын, бірақ батырма болмайтынын айт.
4. **Жабық Telegram канал** бар ма? Жоқ болса — ашуды көрсет (төменде).
5. **Чекті кім тексереді** (Kaspi-ге кімнің ақшасы түседі) — сол адамның Telegram-ы керек.

Ойдан қоспа: баға, сілтеме, атау — тек пайдаланушыдан.

## 2. Бот ашу (пайдаланушы жасайды, сен қадамдап айтасың)
1. Telegram іздеуіне **@BotFather** (көк белгісі бар) → **Старт** → **/newbot**.
2. Аты: мысалы «Курсқа төлем». Username: соңы **bot** (мысалы `aigerim_kurs_bot`).
3. BotFather **токен** береді. ⚠️ «Токенді чатқа жазбаңыз — кейін арнайы бетке қоясыз» деп ескерт.

## 3. Ботты жариялау
```bash
$BT new <аты>        # config.json — 1-бөлімдегі жауаптарды жаз (ADMIN_ID, CHANNEL_ID әзірге бос)
$BT publish <аты>    # Cloudflare-ге шығарады, «токен қою беті» сілтемесін береді
```
Cloudflare кілті жоқ болса (`publish` «кілті жоқ» десе) — **sait-jasau** скиллінің 4-бөліміндегідей тіркеу мен кілт қадамдарын бер.

Пайдаланушыға **токен қою бетінің** сілтемесін бер: «Ашыңыз, BotFather берген токенді қойыңыз, «Сақтау» басыңыз. «✅ Бот қосылды» шығуы керек». Бет токенді бір рет қана қабылдайды.

## 4. ID-лерді алу
1. **Иесінің ID-і:** «Ботқа **/id** деп жазыңыз — шыққан санды маған жіберіңіз» (чекті тексеретін адам жазуы керек).
2. **Канал:**
   - Telegram → ✏️ → **Создать канал** → атауы → **Частный** (жабық).
   - Канал → **Администраторы** → **Добавить администратора** → ботты тауып қосу → **«Пригласительные ссылки»** рұқсаты қосулы → Сохранить.
   - Баптауларда **«Запретить копирование»** қосу.
   - Каналға **/id** деп жазу → бот «Канал ID: -100…» береді → маған жіберу (сосын ол хабарламаны өшіруге болады).

ID-лерді `config.json`-ға жаз да, қайта жарияла: `$BT publish <аты>`. Тексеру: `$BT status <аты>`.

## 5. Тексеру (міндетті)
Пайдаланушыға: «Ботқа **/start** деп жазыңыз → кез келген суретті чек ретінде жіберіңіз → сізге «✅ Растау» келеді → басыңыз → каналдың сілтемесі келуі керек». Нәтижесін сұра. Сілтеме келмесе — бот каналда админ емес немесе «Пригласительные ссылки» рұқсаты жоқ.

## 6. Тапсыру
- Боттың сілтемесі: `https://t.me/<username>` — сайтқа, Instagram bio-ға қойылады. Сайт болса (sait-jasau), «Курсқа жазылу» батырмасын осы сілтемеге бағытта.
- Есіне сал: чек келгенде **Kaspi-ден ақша түскенін тексеріп**, сосын ғана «Растау» басу.

## Өзгерту
Баға, Kaspi сілтемесі, атау өзгерсе — `config.json` → `$BT publish <аты>`. Токен қайта қойылмайды.
