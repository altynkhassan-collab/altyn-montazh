# Мульт-оқиға (3-түр)

Видеоны жинау — **suret-video** скиллімен бірдей (`scripts/suret.py`, plan.json, раскадровка, рендер). Сол скиллдің Б бөлімін оқы. Бұл скилл тек **оқиға мен кейіпкерді** қалай жасау керегін айтады.

## 1. Сұрақтар — БІР хабарламада, нөмірлеп, ұсынысыңмен
1. **Бренд және өнім**: не сатамыз, басты сезім (сағыныш, қуаныш, қамқорлық, мереке).
2. **Кейіпкер**: бала / жасөспірім / ана / әже / жануар-талисман? Ұсыныс бер.
3. **Оқиға идеясы**: 2–3 нұсқа ұсын (әрқайсысы бір сөйлем), пайдаланушы таңдасын.
4. **Стиль**: 3D мульт (Pixar сияқты жылы), 2D сурет, аниме — біреуін ұсын.
5. **Дауыс**: баяндаушы әйел/ер, үні.
6. **Соңғы экран**: логотип, слоган, байланыс, батырма.
7. **Ұзақтығы**: 30–45 с (6–9 көрініс) ұсынамын.

## 2. Оқиға құрылымы (6–9 көрініс)
1. **Ілмек (0–3 с)** — кейіпкер және оның қалауы/мәселесі бірден көрінеді.
2. **Даму** — 2–3 көрініс: кедергі, күту, қиындық.
3. **Шешім** — өнім/бренд табиғи түрде көмектеседі (жарнама емес, оқиғаның бөлігі).
4. **Эмоция шыңы** — қуаныш, құшақтау, күлкі.
5. **Бренд** — өнім мен логотип, слоган (соңғы экран).

Мәтін қысқа, әр көріністе 1–2 сөйлем. Баяндау үшінші жақпен, жылы үнмен.

## 3. Кейіпкер паспорты — ең маңызды бөлік
Барлық суретте кейіпкер **бірдей** болуы үшін бір рет толық сипаттама жаз да, оны **әр промпттың ішіне сөзбе-сөз көшір**:
```
CHARACTER: Aruzhan, 7-year-old Kazakh girl, round face, rosy cheeks, big brown eyes,
two long dark braids with red ribbons, pink knitted sweater, cream scarf.
STYLE: 3D animated movie style, soft warm lighting, Pixar-like, cozy winter colors,
vertical 9:16, no text, no logos.
```
Әр көрініс промпты = `STYLE` + `CHARACTER` + сол көріністің әрекеті мен орны + камера (жақын/орта/жалпы).

Пайдаланушыға кеңес қос: «Бірінші суретті жасағаннан кейін, келесілерін **сол чатта** жасаңыз және "осы қыз, сол стильде" деп қосыңыз — кейіпкер бірдей шығады».

## 4. Пайдаланушыға беретін хабарлама
```
🧒 Кейіпкер: ...
🎬 1-көрініс (≈4 с)
🗣 Дауыс: «Аружанның әкесі вахтада. Отыз күн.»
🖼 Промпт: <STYLE> <CHARACTER> Aruzhan stands by a frosty window, marking days on a calendar ...
...
🎙 ElevenLabs мәтіні (бүтін): ...
```
Сценарийді `Сценарий/<аты>.md` файлына сақта.

## 5. Видео жинау
suret-video скиллінің **Б1–Б3** қадамдары. Мультке ерекше:
- `motion`: көбіне `in` және `left`/`right` — жұмсақ, баяу.
- Субтитр стилі: `"sub_style": "box"`, акцент түсі — оқиғаның негізгі түсі.
- Эмоция шыңындағы көріністі ұзағырақ ұста (5–6 с).
- Соңғы экран: `"bg": "image"` (соңғы көрініс бұлдыр фон) + логотип + слоган.

## Ережелер
- Балалар бейнесі — тек жылы, қауіпсіз жағдайларда.
- Танымал мульт кейіпкерлерін (Disney, Pixar т.б. кейіпкерлерін) салдырма — тек өз кейіпкеріміз. «Pixar-like» тек стильді сипаттайды.
- Ойдан факт қоспа (бренд тарихы, жылы, марапаты — тек пайдаланушыдан).
