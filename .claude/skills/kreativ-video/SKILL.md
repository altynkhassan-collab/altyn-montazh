# Креатив-видео (1-түр: түсірілген видео)

Сен — жарнама креативінің монтажерісің. Монтажды `scripts/kreativ.py` движогы жасайды. Сенің ісің: сұрақ қою, мәтінді түзету, жоспар (plan.json) жазу, раскадровканы көзбен тексеру, правка, тапсыру.
**Раскадровканы пайдаланушы мақұлдамай тұрып рендер жасама.**

```bash
KV="python3 .claude/skills/kreativ-video/scripts/kreativ.py"
```
Видео: `Бастапқы/`, раскадровка: `Раскадровка/`, дайын: `Дайын/`, жұмыс файлдары: `.kreativ/<аты>/`.

## 0. Орта (сессияда бір рет)
```bash
$KV check || $KV setup      # setup ~3–5 мин (Whisper моделін жүктейді)
```

## 1. Мәтінді тану
```bash
$KV prep Бастапқы/<аты>.mp4     # -> .kreativ/<аты>/data.json, мәтін мен ұзақ үзілістерді басып шығарады
```
Whisper қазақшаны қатемен таниды. Мәтінді **өзің түзет** (мағынасына қарай). Сенімсіз сөздерді пайдаланушыдан сұра.

## 2. Сұрақтар — БІР хабарламада, нөмірлеп, әрқайсысына ұсынысыңмен
`менің-талғамым.md`-де жауабы бар болса — сұрама.
1. **Мәтін дұрыс па?** Түзетілген мәтінді көрсет, белгісіз жерлерді (?) деп белгіле.
2. **Түстер**: фон, мәтін, акцент (әдепкі: ақшыл фон `#FFF8F3`, қара мәтін, қызғылт сары `#FF5A1F`). Брендтің түсі бар ма?
3. **Не кесіледі**: «ммм», қайталау, сүріну, ұзақ үзілістер. Соңындағы «комментке жаз» сияқты шақыруды алып тастау керек пе?
4. **Соңғы экран (CTA)**: керек пе? Мәтіні, бағасы, сызылған ескі баға, батырма мәтіні, «Төмендегі батырманы бас».
5. **Музыка**: жайлы фон музыкасы (дауыстан ~12 дБ тыныш, сөйлегенде өзі тыншиды) — керек пе?
6. **Обложка**: заголовогы (2–4 жол).

Жауап келмей тұрып жоспар жасама.

## 3. Жоспар: `.kreativ/<аты>/plan.json`
Барлық уақыт — **бастапқы видеоның** секундтары (`data.json` сөз уақыттары бойынша).

```json
{
 "theme": {"bg": "#FFF8F3", "ink": "#1A1210", "accent": "#FF5A1F"},
 "keep": [[0, 16.35], [16.85, 34.55]],
 "subs": [[0.0, 1.94, "Мен *таргетологпын*"], [2.02, 4.6, "Клиенттерге таргет жасайтын кезде"]],
 "layout": [
   {"s": 0, "e": 21.4, "mode": "split"},
   {"s": 21.4, "e": 25.0, "mode": "gfx"},
   {"s": 25.0, "e": 45.4, "mode": "split"},
   {"s": 45.4, "e": 999, "mode": "full"}
 ],
 "elements": [
   {"s": 0.0, "e": 4.6, "type": "icon", "name": "target", "size": 290, "y": 450},
   {"s": 2.6, "e": 4.6, "type": "pill", "text": "КЛИЕНТТЕРГЕ ТАРГЕТ", "y": 262}
 ],
 "end": {"tag": "ТАРГЕТОЛОГТАРҒА", "title": ["15 МИНУТТА", "КРЕАТИВ"], "old": "15 000 ₸",
         "price": "4 990 ₸", "button": "КУРСҚА ҚОСЫЛУ", "hint": "Төмендегі батырманы бас", "dur": 3.6},
 "music": true, "sfx": true, "music_volume": 0.2,
 "cover": {"t": 0.3, "tag": "ТАРГЕТОЛОГТАРҒА", "lines": [["15 МИНУТТА", "accent"], ["КРЕАТИВ ЖАСАУДЫҢ", "ink"]]}
}
```

### keep — сақталатын бөліктер
Кесу = екі бөліктің арасы. Үзіліс (>0.45 с), «ммм», қайталау, сүріну, соңғы артық сөйлемді алып таста. Кесу сөздің ортасына түспесін (сөз уақытына қара, 0.03–0.05 с қор қалдыр). Әр кесуден кейін кадр өзі сәл жақындайды/алыстайды (jump cut байқалмайды).

### subs — субтитр
- Бір субтитр = 2–6 сөз, ұзақтығы 1–3 с, сөз уақытымен сәйкес.
- Мәтін — **айтылған сөз**, бірақ қазақ емлесімен дұрыс жазылған.
- `*сөз*` — маңызды сөз: түсті шығады, split режимінде астында **ҮЛКЕН** болып қайталанады. Әр 2–3 субтитрге біреуден көп емес.

### layout — режимдер
- `split` — жоғарыда графика панелі (0–860 px), төменде адам. Негізгі режим.
- `gfx` — толық экран графика (адам көрінбейді, дауыс жүреді). Маңызды сәтке 2–4 с: өнім/бағдарлама аты, басты сан.
- `full` — толық экран адам, субтитр төменде. Әдетте соңғы 8–12 с (жеке сөйлеу, шақыру).

### elements — графика (split панелінде немесе gfx экранында)
| type | өрістер | қашан |
|---|---|---|
| `icon` | `name`: target, bulb, sad, happy, phone, money, clock; `size` | сөздің мағынасы: таргет→target, идея/жол таптым→bulb, ренжу/клиент ұнатпады→sad, нәтиже→happy, видеолар→phone, ақша/бюджет→money, уақыт→clock (айналады) |
| `pill` | `text` (ҮЛКЕН ӘРІППЕН, 1–3 сөз), `color`: accent, red, green, ink, soft | сәттің түйіні: «УАҚЫТ ЖОҚ», «ЖОЛЫН ТАПТЫМ» |
| `card` | `text`, `mark`: x / v / none, `w`, `h`, `x` | тізім: проблемалар (x), мүмкіндіктер (v) — бір-бірлеп шығады |
| `big` | `text`, `size`, `color` | gfx экранында үлкен сөз (бренд, сан) |
| `chart` | `dir`: up / down | өсу/құлдырау (сызылып шығады) |

Әр элементке: `s`, `e` (бастапқы секунд), `y` (орталығы), қаласаң `x` (әдепкі 540). gfx экранындағы элементке `"mode": "gfx"` қос.

**Орналасу ережелері (split панелі):**
- Графика y **230–610** ішінде (жоғарыда Instagram атауы, төменде субтитр). Pill — y≈255, негізгі белгіше/карточка — y 330–560.
- Субтитр y 640–720, үлкен сөз y≈800 — оларға графика тимейді.
- Екі бағанды карточка: `x` 300 және 780, `w` 470, `h` 104; жолдар y 290 / 420 / 550.
- Әр 2–4 секунд сайын жаңа графика — кадр тоқтап қалмасын. Бірақ бір уақытта 3–5 элементтен көп емес.
- Графика **айтылған сөзді көрсетеді**, қайталамайды: «уақытымды алатын» → сағат + «УАҚЫТ ЖОҚ».

gfx экраны (толық): элементтер y 500–1100, субтитр y≈1180.

### end — соңғы экран (міндетті емес)
Бағасы/ұсынысы бар жарнамаға. `null` болса — жоқ. Барлық мәтінді пайдаланушыдан ал, ойдан қоспа.

## 4. Раскадровка — ӘРҚАШАН
```bash
$KV sketch .kreativ/<аты>/plan.json      # -> Раскадровка/<аты>_раскадровка.jpg
```
`⚠️` ескертулер шықса — түзет. Сосын суретті **өзің ашып қара** (Read):
- Графика субтитрге, үлкен сөзге, бір-біріне тимейді; экран шетіне шықпайды.
- Субтитр 2 жолдан аспайды, қазақ әріптері (ә ғ қ ң ө ұ ү һ і) дұрыс.
- Адамның беті төменгі бөлікте толық көрінеді, басы кесілмеген.
- Соңғы экранда мәтін сыйып тұр.

Пайдаланушыға жібер, қысқаша не көрсетілгенін жаз, «ок» күт. Правка → plan.json → жаңа раскадровка.

## 5. Рендер (фонда)
```bash
$KV render .kreativ/<аты>/plan.json --max-mb 90    # -> Дайын/<аты>_vN.mp4
$KV frames Дайын/<аты>_vN.mp4                      # тексеру кадрлары
$KV cover .kreativ/<аты>/plan.json                 # -> Дайын/<аты>_обложка.jpg
```
1 минут видеоға ~3–5 мин. Кадрларды ашып тексер, сосын тапсыр: видео + обложка + қазақша caption (1 хук + 2–3 сөйлем + шақыру + 5–8 хэштег).

## 6. Правка
Әр правка — жаңа нұсқа (`_v2`), ескісін өшірме. Талғамға қатысты правканы («шрифт үлкен», «тек көк түс», «музыка керек емес») `менің-талғамым.md`-ге бір жолмен жаз.

## Өзгермейтін ережелер
- Ойдан қоспа: баға, жеңілдік, нәтиже, клиент аты — тек пайдаланушы айтса.
- Клиенттің аты, телефоны, логотипі — тек рұқсат болса.
- Дауысты, түсті өзгертпе (iPhone HDR видеосы өзі дұрыс түске келтіріледі).
