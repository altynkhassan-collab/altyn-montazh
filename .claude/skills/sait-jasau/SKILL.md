# Сайт жасау

Пайдаланушы телефонмен жұмыс істейді. Код көрсетпе, техникалық сөз айтпа. Ретін бұзба:
**сұрақтар → эскиз → мақұлдау → интернетке шығару → сілтеме беру.**

```bash
ST="python3 .claude/skills/sait-jasau/scripts/sait.py"
```
Сайттар: `Сайттар/<аты>/` (`index.html` + суреттер/видео бір папкада), эскиз: `Раскадровка/`.

## 1. Сұрақтар — БІР хабарламада, нөмірлеп, әрқайсысына ұсынысыңмен
1. **Сайт не үшін?** Жеке бренд/портфолио, курс/қызмет сату, бизнес (кафе, той залы, дүкен), шақыру.
2. **Атауы** (сайттың басындағы аты) және **адресі** үшін ағылшынша қысқа сөз (мысалы `altyn`, `sultan-basha`).
3. **Стиль:** `neon` — қара фон + жарқыраған түс (заманауи), `light` — ақшыл, жұмсақ, `gold` — қара + алтын (премиум, той, мейрамхана). Акцент түсі (брендтің түсі болса — сол).
4. **Мазмұны:** кім/не, 3–6 қызмет немесе артықшылық, баға (болса), сандар/нәтижелер (тек нақты), пікірлер (тек нақты скриншоттар).
5. **Суреттер мен видеолар:** фото, логотип, жұмыс мысалдары — чатқа жіберсін.
6. **Байланыс:** WhatsApp нөмірі, Instagram, Telegram, мекенжай (2GIS/Google Maps сілтемесі), төлем сілтемесі (Kaspi) — қайсысы керек.
7. **Негізгі батырма** не істейді: WhatsApp-қа жазу, курсқа жазылу, брондау, қоңырау шалу?

`менің-талғамым.md`-де жауабы бар болса — сұрама. Жоқ дерекке ойдан мән қоспа: сан, пікір, баға, мекенжай — тек пайдаланушыдан.

## 2. Сайтты жаса
```bash
$ST new <аты>        # Сайттар/<аты>/index.html — дайын шаблоннан (стиль, анимация, батырмалар бар)
```
Шаблонды пайдаланушының мазмұнына қарай қайта жаз:
- `<body class="neon|light|gold">` — стиль. Акцент: `:root`-тағы `--or`, `--or2`, `--glow`.
- Бөлімдер: nav → бірінші экран (фото, тақырып, 1–2 сөйлем, негізгі батырма) → сандар → жұмыстар/өнімдер → қызметтер → ұсыныс/баға → автор/біз туралы → пікірлер → сұрақ-жауап (`<details>`) → байланыс → төменгі тұрақты батырма. Керек емесін алып таста.
- Суреттер мен видеоларды `Сайттар/<аты>/` ішіне сақта, атын латынша, бос орынсыз қой (`photo.jpg`, `work1.mp4`). Үлкен фотоны 1200 px-ке дейін кішірейт, видеоны 720p, 8–15 с, `-crf 28` етіп сығымда (сайт телефонда тез ашылсын).
- WhatsApp: `https://wa.me/7XXXXXXXXXX?text=...` (нөмір 7-ден басталады, бос орынсыз). Телефон: `tel:+7...`. Instagram: `https://instagram.com/<ат>`.
- Мәтін қысқа, қазақша, «сіз» деп. Тақырыптар — пайда туралы («15 минутта…», «Тойыңыз есте қалсын»).
- Бөтен адамның сайтын, логотипін, мәтінін көшірме. Танымал адамның суретін рұқсатсыз қойма.

## 3. Эскиз — ӘРҚАШАН
```bash
$ST sketch Сайттар/<аты>     # -> Раскадровка/<аты>_сайт-эскиз.jpg (телефондағы толық бет)
```
`⚠️` шықса (файл жоқ, бет көлденең жылжиды, қате) — түзет. Эскизді **өзің ашып қара**: мәтін сыйып тұр, суреттер орнында, батырмалар көрінеді. Сосын пайдаланушыға **файл жіберу құралымен** жібер, бөлімдерін қысқаша тізіп жаз, «ок» немесе правка күт.

## 4. Интернетке шығару (Cloudflare, тегін)
Бірінші рет — Cloudflare кілті керек:
1. `$ST check` — «✅» болса, 3-қадамға өт.
2. Болмаса, пайдаланушыға қадамдап түсіндір:
   - **dash.cloudflare.com** → email-мен тіркелу (тегін) → сол жақ мәзірден **Workers & Pages** бөлімін бір рет ашу;
   - **dash.cloudflare.com/profile/api-tokens** → **«•••» / Create Token** → **Edit Cloudflare Workers** → **Use template**;
   - **Account Resources:** өз аккаунты; **Zone policy** — қоқыс жәшігі арқылы өшіру;
   - **Continue to summary → Create Token** → кодты көшіру (чатқа жібермесін!).
   Сосын `request_credential` құралымен **api.cloudflare.com** хостына кілт сұра (қауіпсіз форма ашылады; ішінде `:` белгісі жоқ код). Құрал жоқ болса — орта баптауындағы **Network secrets** арқылы қосуды түсіндір. `$ST check` қайта тексер. «Аккаунтқа рұқсаты жоқ» десе — токенде Account Resources таңдалмаған.
3. Жариялау:
```bash
$ST publish Сайттар/<аты>    # -> https://<аты>.<subdomain>.workers.dev
```
Жаңа адрес 1–5 минутта ашылады. Сілтемені бер және: «Instagram bio-ға қойыңыз: Профильді өңдеу → Ссылки → Добавить внешнюю ссылку».

## 5. Өзгерту
Правка → `index.html` → `sketch` → мақұлдау → `publish` (сол адрес жаңарады). Телефонда ескі нұсқа көрінсе — «бетті жаңартыңыз» де.
Сайтты өшіру (пайдаланушы сұраса ғана): `$ST unpublish <аты>`.

## Сайт түрлеріне кеңес
| Түрі | Міндетті бөлімдер | Негізгі батырма |
|---|---|---|
| Портфолио / жеке бренд | фото, сандар, жұмыстар, қызметтер, байланыс | WhatsApp-қа жазу |
| Курс / қызмет сату | ұсыныс, не үйренеді, кімге, автор, баға, сұрақ-жауап | Сатып алу / жазылу |
| Кафе, той залы, дүкен | фото, мәзір/баға, акция, мекенжай + карта, жұмыс уақыты | Брондау (WhatsApp) |
| Тойға шақыру | есімдер, күні + кері санақ, мекенжай + карта, бағдарлама | «Келемін» (WhatsApp) |
