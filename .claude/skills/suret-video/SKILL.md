# Сурет-видео (2-түр: ИИ суреттерімен жарнама)

Жұмыс екі бөліктен тұрады:
- **А. Дайындық** — сен сценарий, сурет промпттары мен дауыс мәтінін жазасың; пайдаланушы суретті ChatGPT-де, дауысты ElevenLabs-та жасайды.
- **Б. Жинау** — `scripts/suret.py` движогы суреттер мен дауыстан видео жасайды.

```bash
SV="python3 .claude/skills/suret-video/scripts/suret.py"
```
Орта: `kreativ-video` скиллінің `check`/`setup` командасы (ортақ).

## А1. Сұрақтар — БІР хабарламада, нөмірлеп, ұсынысыңмен
`менің-талғамым.md`-де жауабы бар болса — сұрама.
1. **Не жарнамалаймыз?** Өнім/қызмет, брендтің аты, басты артықшылығы (2–3 факт). Ойдан факт қоспа.
2. **Кімге?** Аудитория (жас, қала, мәселесі).
3. **Ұзақтығы**: 25–40 с ұсынамын (6–8 сахна).
4. **Көңіл-күй және стиль**: мысалы «жылы, кинематографиялық, алтын түстер», «жарқын, жастарға», «премиум». Брендтің түсі бар ма?
5. **Дауыс**: әйел/ер, жасы, үні (жұмсақ, жігерлі). Қай тілде?
6. **Соңғы экран**: брендтің логотипі (сурет), мәтін, баға, батырма, байланыс (мысалы, сайт немесе Instagram). Керек пе?
7. **Обложка** заголовогы.

## А2. Сценарий — пайдаланушыға бір хабарламада бер
Сахна саны 6–8, әрқайсысы 3–6 секунд. Әр сахнаға:
```
🎬 1-сахна (≈4 с)
🗣 Дауыс: «Әр саяхаттың өз тарихы бар...»
📝 Экрандағы жазу (болса): TURKISTAN
🖼 Сурет промпты (ChatGPT-ге көшіріп қоюға):
Vertical 9:16 photo, cinematic, warm golden light. A young Kazakh woman (25, long dark braid,
blue scarf with Kazakh ornament, camel coat) at a train station, smiling, holding a small
square chocolate. Shallow depth of field, photorealistic, 35mm. No text, no logos.
```
**Промпт ережелері:**
- Ағылшынша жаз (ChatGPT суретті ағылшынша дәлірек салады), басында әрқашан `Vertical 9:16`.
- Кейіпкер бірнеше сахнада болса — **сыртқы түрін әр промптта сөзбе-сөз бірдей** қайтала (жасы, шашы, киімі, түсі). Сонда барлық суретте бір адам болады.
- Стиль сөздерін (жарық, түс, камера) барлық промптта бірдей ұста.
- `No text, no logos` — суретке жазуды біз өзіміз қосамыз (ИИ қазақ әріптерін қате салады).
- Өнімнің өз суреті болса — пайдаланушыға: «өнімнің фотосын ChatGPT-ге қоса жіберіп, "осы өнімді суретте қолдан" деп жазыңыз» деп айт.
- Нақты адамның, атақты адамның бет-бейнесін салдырма.

Сосын **дауыс мәтінін бүтіндей** бөлек бер (ElevenLabs-қа көшіріп қоюға):
```
🎙 ElevenLabs мәтіні:
Әр саяхаттың өз тарихы бар... Ал әр қаланың — өзіне тән дәмі бар.
```
Нұсқау қос: «ElevenLabs → Text to Speech → мәтінді қойыңыз → дауыс таңдаңыз → Generate → Download (mp3)». Сахналар арасында кідіріс керек болса, мәтінге `...` немесе жаңа жол қой.

Сценарийді `Сценарий/<аты>.md` файлына да сақта.

## А3. Файлдарды қабылдау
Пайдаланушы суреттерді **ретімен** (1, 2, 3…) және дауыс файлын чатқа жібереді немесе `Бастапқы/<аты>/` папкасына салады. Сен оларды `Бастапқы/<аты>/` ішіне `1.jpg`, `2.jpg`… және `voice.mp3` деп сақта. Логотип болса — `logo.png`.

## Б1. Дайындық
```bash
$SV prep Бастапқы/<аты>/ --lang kk     # суреттер тізімі + дауыстағы әр сөздің уақыты
```

## Б2. Жоспар: `.suret/<аты>/plan.json`
```json
{
 "theme": {"bg": "#14100E", "ink": "#FFFFFF", "accent": "#E8B04B"},
 "scenes": [
  {"img": "1.jpg", "s": 0,   "e": 4.4, "motion": "in"},
  {"img": "2.jpg", "s": 4.4, "e": 9.0, "motion": "up", "title": "TURKISTAN", "title_at": 0.4, "title_y": 330}
 ],
 "subs": [[0.0, 2.9, "Әр саяхаттың *өз тарихы* бар..."]],
 "elements": [],
 "end": {"tag": "LENGERSKOE", "title": ["ТӘТТІ ДӘМ"], "lines": ["lengerskoe.kz"], "button": "ТАПСЫРЫС БЕРУ",
         "hint": "Төмендегі батырманы бас", "dur": 3.0, "bg": "image"},
 "music": true, "music_volume": 0.18, "crossfade": 0.45, "sub_style": "box",
 "cover": {"img": "2.jpg", "tag": "ЖАҢА", "lines": [["ТӘТТІ", "accent"], "ҚАЗАҚСТАН"]}
}
```
- **scenes** — дауыстың уақыт сызығы бойынша, үзіліссіз (`e` = келесінің `s`). Ауысу сөйлемнің/ойдың шекарасына, кідіріске түссін (`data.json` сөз уақыттарына қара). Соңғы сахна дауыстың соңына дейін.
- **motion**: `in` (жақындау), `out` (алыстау), `left`/`right` (көлденең), `up`/`down`. Көршілес сахналарда әртүрлі қолдан. `focus: [x, y]` (0–1) — жақындайтын нүкте (мысалы, бет немесе өнім).
- **title** — сахнадағы үлкен ақ жазу (қала, бренд, сан), `title_at` — сахна басынан неше секундтан кейін шығады.
- **subs** — айтылған сөз, қазақ емлесімен; `*сөз*` — акцент түсі. 2 жолдан аспасын.
- **elements** — kreativ-video-дағыдай `pill`/`card`/`icon`/`big` (y — толық экран координаты, 250–1100).
- **end** — соңғы экран. `"bg": "image"` — соңғы сурет бұлдырланып фон болады; `"bg": "theme"` — тема түсі. `logo` — `Бастапқы/<аты>/logo.png` болса өзі қосылады.
- **voice_delay** — дауыс басталмас бұрын кідіріс (с), керек болса.

## Б3. Раскадровка → мақұлдау → рендер
```bash
$SV sketch .suret/<аты>/plan.json       # -> Раскадровка/<аты>_раскадровка.jpg
$SV render .suret/<аты>/plan.json --max-mb 90    # фонда; -> Дайын/<аты>_vN.mp4
$SV cover  .suret/<аты>/plan.json       # -> Дайын/<аты>_обложка.jpg
```
Раскадровканы өзің ашып тексер (субтитр оқылады, тақырып бетке тимейді, суреттің маңызды жері кадрда) → пайдаланушыға жібер → «ок» күт → рендер → `kreativ.py frames` арқылы тексер → видео + обложка + caption тапсыр.

## Ережелер
- Ойдан қоспа: факт, баға, жеңілдік, байланыс — тек пайдаланушыдан.
- Брендтің логотипін ИИ-ге салдырма — пайдаланушының өз файлын қолдан.
- Нақты адамның дауысын клондау — тек өз дауысы немесе рұқсаты болса.
